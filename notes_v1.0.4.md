## Arabic Translation — v1.0.4

**Made for Steam build 25605617.**

> ⚠️ A game update restores the original files; reinstall this release after an update.

### ✨ What's new
- Controller: text is now drawn at the keyboard size, so boxes hold longer text and lines no longer reverse. The in-game font size setting still makes it larger.
- Controller: the name in the centre of the radial menu no longer splits into lines in reverse order.
- Controller: bonus card names on the dice-roll screen read in order and no longer cover the item count.
- Controller: quest objectives in the world-map tooltip read in order, as do quest titles and marker names.
- Controller: tooltip titles of statuses, spells and characters, the skill value line ("+1 to Stealth Checks"), and the names on the trade, examine, container, pickpocket and target screens no longer reverse.
- Controller and keyboard: the carrying-capacity warning, character-creation tile names, map zone names and notifications (tutorial titles, approval, game saved) no longer reverse.
